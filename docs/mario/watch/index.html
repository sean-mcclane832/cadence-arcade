The first run, 10/28-29

Cadence plays Mario

One Cadence brain (cadence-net 0.91.1), World 1-1, on its own. Real NES frames. This is the older brain from before the learning fix; the Mario page has the newer brains that clear levels.

What's happening

  • The brain doesn't see the game like you do. It gets the screen shrunk to a 26 x 32 grid of grey blocks (each block averages 8 x 8 pixels), sky removed, for this moment and the one before. No positions, nothing from the game's memory.
  • It learned by copying a look-ahead coach that tries button plans in saved copies of the game. It never saw the score. No backprop: Cadence's own local learning rule.
  • This run gets past the first Goombas, the pipes and the first pit, then dies at x 1,783 of 3,161, about 56% of the level. It does not reach the flag alone.
  • This is its best round. More training rounds after it did worse: later brains stall around x 300 to 725.
